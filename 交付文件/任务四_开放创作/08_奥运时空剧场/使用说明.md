# 奥运时空剧场

打开 [index.html](index.html) 即可离线演示。页面使用本地打包的 Three.js 三维地球和上一模块的本地 ECharts 文件，不请求在线地图或接口。

## 操作

- 拖动地球旋转、滚轮缩放，点击可见的亮点跳至相应届次。
- 时间轴、上一届/下一届和“播放历届”共同控制年份。页面首屏的举办城市、参赛行数、代表团数、女性参赛行占比以及分析图的竖线随年份更新。
- “代表团”只控制获奖运动员行份额趋势；“运动大类”只控制该运动在历届项目表的出现状态。两种筛选各自使用对应的分母，互不冒充。
- WebGL 不可用时显示明确提示，年份和图表仍可使用；尊重系统的减少动态效果偏好。

## 数据与边界

| 视觉元素 | 数据与口径 |
| --- | --- |
| 三维举办地 | 30 届夏奥主办城市中心的**示意坐标**，非场馆模型、运动员来源地或实时数字孪生。1956 年主标记为墨尔本，马术另在斯德哥尔摩举行。 |
| 首屏指标与规模图 | `任务二_百年全景/02_数据表/A_逐届规模与集中度.csv`，参赛量为运动员行，不是去重人数。 |
| 女性占比 | `任务二_百年全景/02_数据表/C_女性参与获奖与小项.csv`，女性参赛行 / 全部参赛行。 |
| 代表团趋势 | `任务二_百年全景/02_数据表/B_十二代表团逐届份额.csv`，获奖运动员行 / 当届全部获奖运动员行；缺席留空。 |
| 项目更替 | `任务二_百年全景/02_数据表/D_代表项目出现矩阵.csv`，二元出现状态，不代表小项或奖牌数。 |
| 地球边界 | [Natural Earth 110m](https://www.naturalearthdata.com/) 地理边界，经 `world-atlas` 2.0.2 转换；地理底图仅用于定位。 |

这是**空间化数据叙事**，不称实时数字孪生。举办地坐标在 `项目工作区/scripts/build_spacetime_data.cjs` 明列，便于复查。历史结果与 2028 模型预测在不同页面展示；历史小项现行 IOC 授牌的证据边界请参看任务三核验报告。

## 复现

在本文件夹运行 `npm ci`，再运行 `npm run build`。构建脚本从任务二 CSV 生成 `src/data.json`，把 Three.js 与 110m 底图打包到 `assets/app.bundle.js`。`node_modules` 不提交，`package-lock.json` 固定依赖版本。网页仍可不安装依赖直接打开已构建的 `index.html`。
