# 证据等级图｜使用与复算

这张图用于正式报告第20页、任务三入口和视频讲解。主结论是巴黎2024年西班牙由小项金牌榜第15变为运动员行金牌榜第5；历史三届只用于挑战“换单位会重排榜单”的机制，不用作现行IOC授牌的证明。

## 图中数字

- **329**：巴黎2024外部逐项结果层的小项数；IOC公开回顾核对的是赛事总数。326条上游结果链接直接提供，3条构造链接已单列，不能写成329条均已手工读页核对。
- **555**：2008、2012、2016三届历史代理中，完成Olympedia独立公开逐运动奖牌表配对的项目数。548项三色一致，7项差异；一致并非现行IOC逐项核验。
- **7 = 4 + 2 + 1**：4项是旧抓取存档缺一色；2项涉及赛后奖牌变动；1项为原铜牌撤销而继任授牌未从IOC逐项决定确认。逐条页码、协会与IOC公告见[双来源核验报告](../../任务三_专题深挖/S2_口径的魔力/08_逐项外部核验/Olympedia独立交叉核验/双来源核验报告.md)。

## 局部排名敏感性

脚本只变动两项有后续变化证据的小项：2008女子现代五项的铜牌由乌克兰转向白俄罗斯；2012男子皮划艇C1 200米由立陶宛银、俄罗斯铜改为俄罗斯银、西班牙铜。以历史代理榜为起点，按金、银、铜字典序重排；同奖牌组三色完全相同采用并列名次。2008年没有代表团名次变化；2012年立陶宛34→35、挪威35→34，其余名次不变；两届前十集合均不变。2012男子举重69公斤级只确认旧铜牌撤销，未把未经IOC逐项决定确认的新铜牌纳入确定性转授；单独撤销旧铜在上述情景里也不进一步改变代表团名次。

此实验**没有**把其余908项转换成现行IOC奖牌表，也不检验未发现的其他后续裁决。其结论是：已知两处后续变动不足以推翻历史代理榜的前十集合；正式双口径重排仍以2024同届比较为主。

复算：在项目根目录运行 `py -3 项目工作区/scripts/build_evidence_hierarchy.py`，生成 `证据等级图.png`、`证据等级图.svg` 和 `证据等级与历史反例_复算结果.json`。输入为任务三S2的 `历史555项独立交叉对照.csv` 与 `S2_跨届双口径排名.csv`。统一正式报告由 `py -3 项目工作区/scripts/refresh_report_preserve_poster.py` 重建，附页插入脚本为 `append_evidence_report_page.py`。
