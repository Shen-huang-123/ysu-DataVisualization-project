# 前端视觉回归说明

本轮检查覆盖总入口、任务一至任务四入口，以及任务三的十个专题，共 15 个页面。自动截图在 1440 像素桌面和 390 像素手机宽度下，分别检查浅色、深色模式的首屏与下一屏，得到 60 个页面状态、120 张标准截图。另有 3 张定点复核截图。检查结果：页面运行错误 0 项，横向溢出 0 项。

## 本轮修正

1. 将共享标题样式限制在普通页面标题区，避免覆盖专题摄影封面的背景。
2. 将七个专题封面的巨大字母编号改为低调圆形纹样，避免抢夺标题视觉重心。
3. 调整 S2 深色模式的数据卡与五环装饰的位置，使内容保持清楚、不被遮挡。
4. 调整 S1 数据卡、S7 王朝时间轴卡片和筛选栏的深色配色，修复浅字灰底的问题。

## 五环导览交互更新

根目录首页和交付目录的 36 个网页入口现共用轻量五环导览。左下角的五环按钮用外圈显示阅读进度；点击展开四任务阅读路线，支持 Escape 关闭、键盘焦点和本地文件跳转。筛选器、选项卡及按钮操作触发短暂反馈；用户选择减少动态效果时关闭该反馈。导览独立于数据层，不修改图表计算和统计口径。

运行 `py -3 项目工作区/scripts/olympic_interaction_layer.py` 可在页面重新生成后恢复此交互；运行 `node 项目工作区/scripts/qa_olympic_interaction.cjs` 可检查全部 37 页的桌面与手机状态、导览开合、四个本地任务链接和运行错误。本轮结果为 37 页检查、0 项错误。数据新闻页的主场对照表另加了手机横向滚动容器，避免整页横向溢出。

## 首页固定舞台穿隧
