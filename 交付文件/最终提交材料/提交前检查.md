3. **确认自拟专题备案要求。** 赛题示例框架写明 S7 需备案；S7—S10 已作为扩展研究展示，正式参赛资格以主办方确认和备案记录为准。
4. **核实主办方的截止时间、提交渠道及视频/海报规格。** 赛题文件中时间和渠道均为占位；收到通知后按实际要求提交。
5. **线上与本地版本一致性。** 2026-11-15 复核显示公开 Sites 仍为 2026-11-09 的版本 43：旧作品入口返回 HTTP 200，但最新“反例与证据链”页面返回 404。当前 Sites 项目在此账号下可读取却无法取得源仓库写入凭据（`project_not_found`），故不能宣称新版已上线。正式展示先用本地交付包或 GitHub 最新 `main`；若使用该网址，须由拥有发布权限的账号同步新版并重新逐页验收。
6. **最终人工巡检。** 用提交电脑逐页打开PDF和网页，检查中文、图片、跳转、移动端与离线入口；自动验收只能覆盖文件、数据和脚本规则。
7. **在其他电脑安装依赖并重跑。** 双击[一键异机复现核验.cmd](一键异机复现核验.cmd)；脚本会在临时目录新建 Python 环境、安装依赖、复制原始CSV和必要代码、重算四项任务的关键统计，并写出`异机复现结果.json`。本机已做干净环境与隔离目录核验；第二台实体电脑或评委环境仍需实测。需要 Python 3.11—3.13 和安装依赖所需的网络。

原始CSV不随包提交；重现代码可从资料文件读取原始数据。外部数据的来源与口径限制以各任务说明为准，不把运动员记录数称作官方小项奖牌数。
