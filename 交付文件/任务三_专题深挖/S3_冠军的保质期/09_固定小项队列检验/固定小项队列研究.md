# 固定小项队列：王朝变短是否只是项目表更替？

从 S7 原有 4,511 次控制权转移出发，预先规定一个严格队列：同名 Event 在 **1960—2016 每届**均出现，且每两个相邻实际举办届次都有金牌代表团可比。得到 **113 个小项、1582 次转移**。这排除了项目新设、退出和名称显著变化所形成的机械组成效应，但保留稳定举办的小项存在选择偏差。

主比较避开 1980—1992 的抵制与政体转折，把 1964—1976 的 4 个目标届次与 1996—2016 的 6 个目标届次比较。固定小项卫冕率从 **34.5%** 降为 **27.1%**，差 **-7.37 个百分点**。按小项成组重抽样 10,000 次的差值 95% 区间为 **[-13.20, -1.62] 个百分点**。

保留中间转折期、改用 1964—1988 对 1992—2016 后，卫冕率为 28.7% 对 25.5%，差值减小。逐一排除一种运动后，主比较差值落在 **-8.65 至 -3.54 个百分点**。因此“固定项目后下降仍存在”有数据支持，但下降幅度依赖时间窗。

本结论描述的是**代表团对小项金牌的连续控制**，不是个人冠军寿命，也不能归因于运动员变弱。Event 名称相同不能保证项目规则完全不变；样本仅为长期存续小项，历史小项为主数据代理而非逐项 IOC 官方表。图、逐届转移、纳入队列与运动排除表可在本文件夹复核。运行 `python 项目工作区/scripts/dynasty_fixed_panel.py` 重建。
