# 十专题视觉设计参考

本轮借鉴的是数据叙事的设计方法和作品类型，没有复制外部作品的图形、代码或配色文件。

- [The Pudding 作品与创作方法](https://pudding.cool/resources/)：按叙事问题选择可视化形式，让读者逐步探索；本项目将趋势、人物、项目和代表团分别设计成不同图形。
- [Information is Beautiful Awards 获奖作品展示](https://www.informationisbeautifulawards.com/showcase?action=index&controller=showcase&page=1&pcategory=winner&type=awards)：参考其多样化的信息结构和一图一问题的表达方式。
- [Online Journalism Awards 视觉叙事奖项](https://awards.journalists.org/awards/visual-digital-storytelling/)：参考新闻叙事中视觉、说明和证据并置的方式。

各页对应的设计语汇：S1 实验室，S2 编辑式叙事，S3 历史档案，S4 岛屿气泡，S5 年代刻度，S6 人物鉴证，S7 电影式时间轴，S8 杂志面积图，S9 项目博物馆，S10 项目图谱。动效包括数据线绘制、气泡入场、条形增长、卡片悬停与阅读进度；用户设置“减少动态效果”时会关闭非必要动画。所有新增图形由专题数据生成。

摄影版增加了十张真实奥运历史和比赛现场照片。照片来源、作者与许可逐项记录在[图片来源与许可](媒体/图片来源与许可.html)；它们用作场景配图，不充当统计证据。页面图片保存在本地，离线打开也能显示。
