# S3 缺席的代表团

1980 与 1984 两届的参赛规模突然变化。图中展示的是数据集里实际出现的代表团数量，而不是政治事件的完整名单。

## 发现

抵制潮留下了可见的参赛缺口，但仅凭总量无法判断单个国家为什么缺席。苏联、独联体联队、俄罗斯、俄罗斯奥委会代表队和个人中立运动员也不能直接合并成同一支队伍。

- **1980 / 1984**：80 / 140 个代表团出现在数据中；对照前后届，先确认规模变化，再查事件背景。
- **历史身份**：个人中立运动员 2024—2024 / 独联体联队 1992—1992 / 联邦德国 1968—1988 / 民主德国 1968—1988 / 德国 1896—2024 / 俄罗斯奥委会代表队 2020—2020 / 俄罗斯 1900—2016 / 苏联 1952—1988。原始数据仍保留代表团代码，不宜直接加总成一个“国家”。

## 方法

按届次去重代表团代码；对 1980、1984 及前后届做描述性比较。历史代表团身份保留原码。

## 局限

代表团数量是数据集覆盖值；抵制原因和代表团身份须结合外部史料确认。1906 排除，1956 双城按一届统计。

数据由 `项目工作区/outputs/olympics_flagged.csv.gz` 生成。运行 `项目工作区/scripts/task3_ten_topics.py` 可复现本页。
