# 一键复现说明

[评审复跑验收](../04_质量检查结果/评审复跑验收/index.html)覆盖 Q1–Q6、四组关键读数和两项修订案例。仓库根目录运行 `py 项目工作区/scripts/run_judge_data_audit.py --csv 路径/olympics_dataset.csv`，需要 pandas、beautifulsoup4 和 PyMuPDF。

## 最简单的运行方式

Windows用户双击`一键运行任务一.cmd`。启动器会自动：

1. 优先寻找`runtime/python.exe`便携解释器；
2. 若未附带便携环境，则寻找系统中的`py -3`或`python`；
3. 检查pandas依赖；
4. 自动定位`olympics_dataset.csv`；
5. 执行审计与归一，并把终端输出保存到`99_运行生成/run_log.txt`。

## 原始CSV自动定位顺序

1. `OLYMPICS_CSV`环境变量指定的完整路径；
2. 当前运行目录；
3. 任务一目录；
4. 总项目的`资料文件/原始资料`目录。

## 免安装包兼容方式

启动器已经支持便携Python：将可分发的Python运行时放入`runtime`并确保入口为`runtime/python.exe`，即可在未安装Python的Windows电脑上运行。批处理层只使用ASCII字符，中文路径交由Python入口处理，避免不同Windows区域设置造成乱码。考虑到便携Python连同pandas通常会显著增大提交包，本目录默认不重复打包约数百MB的开发运行时；是否附带应以比赛上传大小限制为准。

## 刷新2024逐项数据

运行`python 03_复现代码/同步2024官方小项.py`。该脚本下载开放数据快照，断言329个事件键、329个金牌单元和零完全重复，并重建`02_交付数据/2024官方329小项奖牌表.csv`。
