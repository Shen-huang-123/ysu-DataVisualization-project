# 不依赖 Olympics.com 历史小项页的官方来源路线

2026-11-13 已通过 LA84 Foundation 的公开馆藏 API 定位并核实：北京2008有38份、伦敦2012有36份由当届组委会编制的官方分项目成绩册。完整索引、馆藏页和可下载PDF链接见 `北京2008_伦敦2012_官方分项成绩册索引.csv`；索引由 `python 项目工作区/scripts/la84_official_results_inventory.py` 复建。

已实际下载 `伦敦2012_足球官方成绩册_样本.pdf`，184页、1,514,409字节，SHA256 为 `3defd13012a86268233af99a04404ac7b1585ba813d08c845a624e9ef17ed1df`。PDF第一页明确标注 London Organising Committee of the Olympic Games and Paralympic Games Limited，正文可提取。这说明馆藏可作为**赛时一手证据**批量处理。

里约2016的组委会分项成绩册也见于[IOC Olympic World Library 的结果册附件](https://library.olympics.com/Default/digitalCollection/DigitalCollectionAttachmentDownloadHandler.ashx?documentId=165320&parentDocumentId=165312)及单项协会网站；本机直连IOC文献库只返回HTML错误页，尚未形成完整本地索引。

**证据边界**：组委会成绩册通常在赛后即定稿，不会随日后的禁赛和奖牌重分配更新。因此即便把三届赛时成绩全部重建，也不能直接称为“2026现行IOC三色结果”。正确做法是：官方成绩册重建赛时基线 → IOC奖牌重分配公告逐案覆盖 → 将未找到明确修订的小项标作“赛时官方＋已检索后续修订”，而非“现行IOC逐项页已核验”。

2026-11-12阶段的计数是4项现行IOC完整重分配、7项赛时一手补证、899项旧存档；74份索引本身没有被冒充为逐条核验。2026-11-13另取得138项世界田联现行结果，最新分层见交付文件/证据边界核验进度.md。

## 2026-11-13 实际落地进度

74份原始PDF已全部下载至 `北京2008_伦敦2012_原始PDF/`，合计约130.5 MB、10,827页；`官方成绩册下载校验清单.csv`逐份记录字节数和SHA256，`74份PDF可读性检查.csv`逐份记录页数及文本可提取性。74份的前五页均有可提取文本。

`2008_2012小项至官方成绩册索引.csv`把尚待复核的593个北京、伦敦小项逐一连接到正确运动的官方成绩册，包括自行车、皮划艇、体操的分册。`2008_2012官方成绩册候选页.csv`自动为其中413项找到候选页，包括64个高风险项中的40项。候选页只为缩小人工审读范围，不宣称该页就是最终奖牌表，更不据此提高“现行IOC逐项已核”计数。

例如伦敦2012女子800米的赛时官方田径成绩册第199页显示俄罗斯、南非、俄罗斯的原领奖顺序；后续[IOC 2026年重分配决议](https://www.olympics.com/ioc/news/ioc-executive-board-approves-olympic-medal-diploma-and-medallist-pin-reallocation-for-london-2012-olympic-games)和[World Athletics现行决赛表](https://worldathletics.org/competitions/olympic-games/the-xxx-olympic-games-6999193/results/women/800-metres/final/result)给出南非、肯尼亚、美国的当前结果。这正说明赛时成绩册不能直接替代现行结果。

另一个交叉例是北京2008男子撑杆跳：赛时官方田径成绩册第98页的铜牌为乌克兰；[IOC取消Denys Yurchenko的赛果](https://www.olympics.com/ioc/news/ioc-sanctions-16-athletes-for-failing-anti-doping-tests-at-beijing-2008)后，[World Athletics现行决赛表](https://worldathletics.org/competitions/olympic-games/the-xxix-olympic-games-6977748/results/men/pole-vault/final/result)及[美国奥委会运动员资料](https://www.teamusa.com/profiles/derek-miles)均显示Derek Miles获铜牌。此项建立了“赛时册→禁赛公告→现行单项协会结果”的完整解释链，但仍不冒充已读取IOC当前小项页。

复算顺序：`python 项目工作区/scripts/la84_official_results_inventory.py` → `python 项目工作区/scripts/download_la84_results_books.py` → `python 项目工作区/scripts/verify_official_books.py` → `python 项目工作区/scripts/link_historical_events_to_books.py` → `python 项目工作区/scripts/locate_official_result_pages.py`。最后一步依赖项目的 `.runtime` 中的 PyMuPDF。
