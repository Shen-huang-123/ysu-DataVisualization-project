# 作品交付清单

作品暂定题目：百年圣火，谁被看见。以扩张、女性参与和统计尺度贯穿；S2为主专题，S1作为通过数据验证后决定篇幅的辅助专题。

## 评分证据

- 数据处理25分：原始文件指纹、至少5项可复现检查、完整运动映射、清洗日志、特殊记录规则、口径敏感性。
- 可视化25分：A奖牌格局、B至少8个代表团、C女性参与、D项目演化各有核心图与100字以上解读；逐图标注口径、分母、范围和来源。
- 分析25分：对口径引起的排名变化进行结构分解；检查团体项目影响及反例；主场表现使用份额和比较组；不预写数据尚未支持的结论。
- 叙事15分：不超过20页报告，300字内摘要，方法、发现、局限、参考资料齐全；海报和视频与可复现数据一致。
- 创新10分：交互切换统计尺度与历史代表团；显示数据缺口和结论敏感性。
- 加分项：完成可本地运行的交互叙事看板，并验证筛选、图表、导出与运行说明。

## 报告页数预算

封面与摘要1页；数据及口径3页；全景A到D共8页；S2专题3页；S1专题2页；结论与局限1页；参考资料1页。目标19页，保留1页调整余量。

## 交付与提交边界

代码与README、清洗数据和映射、质量说明、PDF报告、A1/A2竖版海报、看板、视频脚本及最终视频链接。原始CSV不随提交包分发。数据衍生版本注明CC BY-NC-SA 4.0与三个上游来源。

模板清单允许海报或看板、视频按赛程要求，而赛题正文列出海报和视频；按更完整标准准备两者。正式截止日期、渠道、团队真实信息与视频上传账号仍需在提交阶段落实，不填造示例信息。
