# 数据归一阶段发现

已将76个Sport原值全部映射到明确的运动家族；保留原值及逐行标记，不覆盖原数据。跨家族的Cycling Road, Triathlon有两条记录，分别依据个人计时赛和个人赛标签归入自行车和铁人三项。该判断依赖现有字段，尚未外部核验。

主分析排除1906后为250832条参赛记录、38360条奖牌记录。运动家族是分析层级，不能当作IOC正式大项或小项。

重复候选共涉及2156条原始记录，其中1466条为保留第一条后的重复余量。候选大量集中于1924—1948，不应统一按现代团体项目解释；2020和2024各只有1条余量。剔除余量后，2024女性参赛记录占比变化仅约0.0033个百分点。因此，这种重复处理对2024女性记录占比影响较小，不能据此证明运动员人数统计可靠。

扩展上下文依赖词表后，共8515条记录被标记为generic_or_context_required。这包含Singles、Individual等需结合Sport才能判断的标签，范围比赛题“完全泛化”更宽，不能与赛题约6700条直接比较。其余标签仅标记为specific_label_unverified，仍未核验独立小项。

2024金牌记录前三为USA 131、CHN 71、NED 67。此处是原始奖牌行数；尚未完成官方小项奖牌表的来源核验，不能对其冠以官方排名。

进一步按运动定位，1466条重复余量中1315条属于Art Competitions，占89.7%；其次为帆船42、自行车34、射击27。这是赛题已知问题清单之外需要单独解释的结构性现象，尚不能确定哪些是真重复、哪些来自未保留的作品或子项信息。

下一阶段的核心验证：核查艺术竞赛多记录的历史原因；引入有来源记录的官方小项奖牌榜进行S2比较；对女性、国家曲线和运动家族时间序列完成图表解读。主场效应在取得主办国对照表后分析。
