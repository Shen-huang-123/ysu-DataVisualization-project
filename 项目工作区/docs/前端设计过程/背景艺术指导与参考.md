## 落地方式

1. 将均匀同心线条替换为偏心场馆屋面剖切：宽面、细边和局部反光形成体积。
2. 左下冷光与右上暖光形成统一方向；任务四采用落日侧光。
3. 档案纸页、场地边线、弯道、泳道均使用本地矢量构造。白天呈浅浮雕，夜间呈暗场结构。
4. 阅读中央保留透明遮罩；照片封面、数据图层和独立3D大屏保持自身视觉系统。
5. 背景不可点击、不可聚焦；移动端降低强度，低动态模式不运行视差与呼吸。无需远程模型或网络服务。
