## 布局与交互

- 桌面：图示停留在左侧，右侧文字推进三个问题；上下反向滚动都由当前位置直接计算状态。数字切换只有低幅短过渡，无滚动劫持、全屏遮罩或必须等待的动画。
- 手机及短横屏：取消固定图示；各段文字旁保留该段数值、单位和限制。原有分析区正常滚动。
- 点击画面序号可以直接定位段落并更新 URL 锚点；证据链接进入对应原分析章节。滚动开场不会重置或修改原筛选。
- 任务一详细区采用左侧解释、右侧核对操作；任务三专题按问题组展开；任务四将大块入口收敛为有主次的开放式文本行。
- 任务二主图保留原始聚合与 CSV 导出，补齐坐标、单位、直接数值及空结果提示；历史横轴按真实年份间距绘制。奖牌指标明确是获奖运动员行。
- 资源：共享组件/story-sequence.css 与 story-sequence.js，仅接入这四个入口。无网络运行依赖。关闭 JavaScript 时保留四页原分析内容。
